# Module Informatique 2
Module d'informatique 2. Etude de la gestion des Bases de Données. Langage SQL.
## Découpage du module
Le module est composé de 4 TPs : 
1. [TP1](./TP1%20-%20Interrogation%20SQL/) - interrogation d'une base de données en SQL, en utilisant la base vue en cours/TD (chapitre 9)
2. [TP2](./TP2%20-%20Création%20de%20relations/) - création de relations dans une base de données, leur remplissage, et la gestion de leur droits d'accès. Des interrogations plus complexes qu'au TP1 et des modifications des contenus des relations sont aussi illustrées (chapitre 10)
3. [TP3](./TP3%20-%20Création%20base%20et%20accès/) - accès concurrentiels à une base (chapitre 11)
4. [TP4 (mini-projet)](./TP4%20-%20BDD%20et%20gestion%20de%20restaurant%20(application)/) - création d'un programme d'application exploitant une base de données de gestion de restaurants d'entreprise. La modélisation du problème a été réalisée au cours du TD7. La séance concerne la prise en main du projet et de son environnement, la création des relations et leur remplissage, et l'écriture des premières méthodes Java de manipulation.
